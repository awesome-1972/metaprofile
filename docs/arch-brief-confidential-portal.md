# Архітектура: бріф кандидата, конфіденційність, job-portal

**Дата:** 2026-07-31. Запит власника: таб «Бріф» має показувати фінальний бріф кандидата
(текст/файл/посилання) із швидкою відправкою; опитувальник — лише інструмент підготовки;
конфіденційний пошук ховає назву компанії від кандидатів; публічний job-portal на
metavision.ua з бріфом за посиланням.

## Поточний стан (що вже є)
- `vacancy_briefs.answers` (jsonb, ~15 секцій Q&A) — **опитувальник** для формування бріфу.
  Зараз таб «Бріф» (BriefTab) показує саме його.
- `vacancy_public_briefs` (intro + sections[] + title + status + ai_model) — **фінальний бріф
  кандидата**, структура 1:1 зі зразком (вступ «Наш Клієнт — …» + розділи). Генерується
  `generate-public-brief` (параметр `disclose_client`), є PDF-експорт. Живе в «Підготовці» →
  «Бріф для кандидатів».
- Публічних маршрутів (`/jobs`, `/brief/:token`) НЕ існує.

## Рішення

### 1. Розділити ролі двох сутностей (поміняти, де що показуємо)
- **Опитувальник** (`vacancy_briefs`) → лишається **інструментом Підготовки** (етап 1), у
  роботі не потрібен → прибрати з окремого таба, тримати у PreparationPanel.
- **Фінальний бріф кандидата** (`vacancy_public_briefs`) → стає вмістом таба **«Бріф»**:
  рендер (markdown intro+sections) + PDF-файл + публічне посилання + ручне редагування
  (AI-генерація лишається як помічник «оновити чернетку»).

### 2. Конфіденційність
- Прапорець **`vacancies.is_confidential`** (ставиться на етапі Підготовки).
- Увімкнено → назва компанії НЕ показується ніде candidate-facing:
  - генерація бріфу без назви (intro у стилі «Наш Клієнт — …»); `disclose_client` робимо
    похідним від прапорця (confidential ⇒ disclose_client=false);
  - публічний рендер бріфу / job-portal не віддають `client.name`;
  - листи кандидатам — без назви клієнта;
  - у застосунку — ховати клієнта для ролей без прав (Відвідувач), решта бачить (внутрішня робота).
- Технічно маскування — на рівні (а) генерації, (б) публічного Edge-рендера, (в) UI-гейта.

### 3. Швидка відправка кандидату (файл / посилання)
- Кнопка **«Надіслати бріф»** (у табі «Бріф» і на картці кандидата): PDF-вкладення АБО
  публічне посилання.
- Публічне посилання: `vacancy_public_briefs.public_token` (uuid) + **публічний маршрут
  `/brief/:token`** (без авторизації), рендерить бріф з урахуванням confidential. Токен
  можна відкликати/перегенерувати (`published_at`, `is_link_enabled`).
- Відправка — наявним каналом комунікацій (Resend); шаблон листа з лінком/PDF.

### 4. Job portal (metavision.ua)
- Прапорець **`vacancies.is_public`** (публікувати).
- Публічний список **`/jobs`** — лише `is_public` + `open` вакансії: назва позиції, локація,
  короткий опис (без клієнта якщо confidential), лінк на `/brief/:token`.
- **Безпека:** публічні дані віддавати ТІЛЬКИ через SECURITY DEFINER Edge/RPC під anon, що
  фільтрує `is_public`/`open`/confidential-маскування. Таблиці анону НЕ відкривати (RLS
  лишається закритим; публічний доступ — виключно через контрольований ендпоінт).
- Розміщення: **Варіант A (старт)** — публічні сторінки `/jobs` і `/brief/:token` у цьому ж
  SPA (поза DemoGate/Protected), швидко. **Варіант B (згодом)** — брендований портал на
  metavision.ua, що б'є в той самий публічний Edge. Рекомендую A → потім B.

## Модель даних (зміни)
- `vacancies.is_confidential boolean not null default false`
- `vacancies.is_public boolean not null default false`
- `vacancy_public_briefs.public_token uuid` (+ `is_link_enabled boolean default true`,
  `published_at timestamptz`)
- Публічний Edge `public-brief` (anon): за token → бріф (маскований) + мета вакансії.
- Публічний Edge `public-jobs` (anon): список is_public+open вакансій (масковані).

## План впровадження (фази)
1. **Таб «Бріф» = фінальний бріф** (рендер + PDF + редагування), опитувальник лишити в
   Підготовці. UI-рефактор, майже без міграцій.
2. **`is_confidential`** + маскування клієнта (генерація/рендер/листи/UI-гейт).
3. **Публічне посилання**: `public_token` + `/brief/:token` + Edge `public-brief` + кнопка
   «Надіслати кандидату».
4. **Job portal**: `is_public` + `/jobs` + Edge `public-jobs`. Пізніше — винести на metavision.ua.

## Що переви­користовуємо (не ламаємо)
`vacancy_public_briefs`, `generate-public-brief`, PDF-експорт — уже є. `disclose_client`
зв'язуємо з `is_confidential`. Опитувальник `vacancy_briefs` не чіпаємо — лише перемістити в UI.
