# Показники рекрутменту для аналітики (задача #44)

Легенда джерела даних:
- **✅ Є** — рахується з наявних даних (applications, application_events, offers, candidate_sources, rejections, vacancy_candidate_matches, interviews, pipeline_stages).
- **🟡 Треба поле** — потрібне невелике доповнення схеми/введення.
- **🔵 Треба процес** — потрібен окремий збір (опитування, вивантаження витрат).

## 1. Швидкість (velocity)
- **Time-to-fill** — від відкриття вакансії до прийнятого оферу/закриття. 🟡 (додати `opened_at`/`filled_at` на вакансії або брати created_at + дату accepted оферу).
- **Time-to-hire** — від першого контакту з кандидатом до оферу. ✅ (перша поява заявки → offer.responded_at).
- **Час на кожній стадії** — середній час перебування на стадії. ✅ (application_events `stage_changed` з таймстемпами).
- **Вік відкритих вакансій** — скільки днів вакансія в роботі. ✅ (created_at → today, статус ≠ закрита).
- **Швидкість наповнення воронки** — днів до першого/N-го релевантного кандидата. ✅.

## 2. Воронка й конверсії (по всіх етапах)
- **Конверсія по кожному переходу**: Лонг-лист → Скринінг → Інтерв'ю → Фінал → Офер → Найм. ✅ (рух по стадіях з подій).
- **Наскрізний вихід воронки** — % кандидатів, що дійшли до найму. ✅.
- **Drop-off по стадіях** — де найбільше втрачаємо. ✅.
- **Screen-to-interview**, **Interview-to-offer**, **Offer-to-hire** — покрокові коефіцієнти. ✅.
- **Offer acceptance rate** — accepted / sent оферів. ✅ (offers).
- **Submit-to-interview** — % поданих клієнту, що дійшли до інтерв'ю (якість шортлиста). ✅ (short_list → interview).

## 3. Джерела кандидатів
- **Розподіл кандидатів за джерелом** — скільки з якого джерела. ✅ (candidate_sources).
- **Source of hire** — звідки прийшли саме найняті. ✅.
- **Ефективність джерела** — конверсія «джерело → найм» і «джерело → інтерв'ю». ✅.
- **Вартість джерела (cost per source)** — витрати на джерело / наймів звідти. 🟡 (ввести витрати по джерелах).
- **Швидкість джерела** — середній time-to-hire по джерелу. ✅.

## 4. Якість
- **Quality of hire** — інтегральна якість найму. 🟡 (проксі: середня оцінка компетенцій найнятих + проходження випробувального).
- **Проходження випробувального терміну** — % найнятих, що лишились. 🟡 (додати результат випробувального на заявку/офер).
- **Середній match-score** — по поданих/найнятих (наскільки точно б'ємо в профіль). ✅ (vacancy_candidate_matches).
- **Причини відмов** — розподіл rejection_reasons (де і чому втрачаємо). ✅ (rejections).
- **Submit accuracy** — % поданих клієнту, яких клієнт не відхилив одразу. ✅.
- **Задоволеність hiring-manager/клієнта** — оцінка після закриття. 🔵 (коротке опитування клієнта).

## 5. Вартість та економіка
- **Cost per hire** — сукупні витрати / кількість наймів. 🟡 (ввести витрати: реклама, підписки на джерела, час).
- **Cost per source** — див. п.3. 🟡.
- **Revenue / fee per placement** — гонорар за закриту вакансію. 🟡 (поле гонорару на проєкті/вакансії).
- **Маржинальність по клієнту/проєкту** — виручка − витрати. 🟡.
- **ROI джерела** — наймів × цінність / витрати. 🟡.

## 6. Продуктивність і навантаження
- **Наймів на рекрутера** за період. ✅ (created_by/assignee + offers accepted).
- **Відкритих вакансій на рекрутера** (навантаження). ✅.
- **Кандидатів у роботі / у воронці** зараз. ✅.
- **Завислі кандидати (aging)** — прострочені по SLA. ✅ (SLA-трекер уже є).
- **Заплановані інтерв'ю / офери в очікуванні** — оперативне навантаження. ✅ (interviews, offers sent).

## 7. Розподіли (зрізи)
- **За гео / стилем роботи / пріоритетом вакансії** — з полів вакансії. ✅.
- **За seniority / компетенціями** — зрізи пулу й найнятих. ✅/🟡.
