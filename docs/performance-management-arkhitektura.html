Суть реформи. Усе, що стосується оцінки та розвитку ефективності людей, зводимо в один застосунок «Performance Management». Додаємо новий шар — Data Integration Hub — щоб живі дані (KPI, продажі, фінанси) автоматично підтягувались із систем компанії, починаючи з Google Sheets. Кожен із 8 підходів до performance вмикається/вимикається під конкретного клієнта.

1. Навіщо це потрібно

Сьогодні «performance-функції» розкидані по трьох застосунках: оцінка 360 і компетенції — в Оцінці PRO; KPI-дашборди — в ATS і хабі; метапрограми — окремий застосунок; профіль співробітника — ще окремо. Через це дублюються реєстри людей і довідники, а користувач змушений блукати між системами. Мета — одна логічна точка «ефективність» і менше дублювання «під капотом».

Другий важливий момент: система самодостатня — показники можна заносити прямо в неї. А там, де дані вже ведуться в зовнішніх системах клієнта (Google/MS Sheets, CRM, ERP), їх можна підтягувати автоматично, щоб не дублювати ввід. Тому інтеграція даних будується як окремий опційний шар, а не як обов'язкова умова роботи.

2. Цільова структура (4 рівні)

Рівень 1. Studio Hub — верхній рівень лишається

Єдина точка входу та спільні дані, які не мають дублюватися по модулях:

  • Єдиний реєстр людей та оргструктури — одне «джерело правди» замість окремих списків співробітників у кожному застосунку.
  • Єдиний довідник: компетенції, професії, метапрограми, процеси APQC (частину вже звели — завершуємо).
  • Розробники, адміністрування, доступи.
  • Data Integration Hub нове — конектори до зовнішніх систем (деталі в розділі 4).

Рівень 2. Recruiting (ATS / Metaprofile) лишається як є

Наймання: вакансії, кандидати, воронка, брифи, портал клієнта, офери, конектори джерел (robota.ua, work.ua, Djinni тощо). По суті змін не потребує.

Рівень 3. Performance Management новий консолідований застосунок

Сюди переїжджає все розкидане, згруповане у 5 під-модулів. Кожен підхід — з тумблером «увімк/вимк» під клієнта:

🎯 Цілі
MBO + OKR: узгодження цілей періоду та ключових результатів, трекінг досягнення.
📊 KPI та Scorecards
KPI-підхід + Balanced Scorecard. Цифри тягнуться з Data Integration Hub.
🧭 Оцінка компетенцій
Competency-based + 360°/поведінкова. Метапрограми — як вхідні дані профілю.
📝 Огляди
Щорічна оцінка (rating) + безперервні check-in'и та зворотний зв'язок.
📈 Талант-аналітика
9-box, калібрування, eNPS/NPS, зведені звіти по командах.
⚙️ Конфігуратор методики
Тут клієнт вмикає потрібні підходи та ваги. Один застосунок — різні моделі оцінки.

Рівень 4. Organizational Development лишається

APQC (бібліотека процесів), оргдизайн, аудит процесів. Окремий блок або під хабом.

Наскрізне: Живий профіль людини. Це не окремий модуль, а «підсумковий об'єкт», що збирає докази з усіх модулів: результати оцінок, досягнення KPI/OKR, метапрограми, 360. Саме він показує роботодавцю реальну цінність співробітника чи кандидата.

Система самодостатня. Усі показники можна заносити прямо в неї — інтеграція із зовнішніми системами не обов'язкова. Data Integration Hub лише економить ручну працю там, де дані вже ведуться в Sheets/CRM/ERP. Клієнт може працювати повністю автономно, частково на інтеграціях, або комбіновано — для кожного показника окремо.

Метапрограми не входять до цієї 8-ки як самостійна performance-система — вони працюють як профілюючий вхід у «Оцінку компетенцій» та в Живий профіль.

4. Data Integration Hub — фундамент

Опційний шар (не набір розрізнених імпортів). Якщо клієнт хоче — заносить дані вручну і живе без інтеграцій. Якщо дані вже є в зовнішніх системах — один раз налаштувавши зв'язок, отримує автоматичне оновлення показників. Компоненти:

  • Конектори — Google Sheets (перший), далі Microsoft 365/Excel, CRM, ERP (поетапно).
  • Мапінг — «колонка в їхній таблиці → показник у нас». Налаштовується один раз.
  • Синхронізація — за розкладом + кнопка ручного оновлення.
  • Єдина точка істини для цифр — сюди дивляться KPI, OKR і Scorecards за фактом.
Старт із Google Sheets. Багато клієнтів уже ведуть KPI у Google-таблицях, тож це найшвидший спосіб показати цінність: підключаємо таблицю → мапимо колонки → показники оживають у Scorecards без ручного вводу.

Схема потоків даних

Зовнішні дані → Integration Hub → показники в Performance Management. Реєстр людей живить усі модулі; результати всіх модулів стікаються у Живий профіль.

5. Що спрощується

  • Оцінка PRO як окремий застосунок фактично розчиняється в Performance Management.
  • Зникають дублі реєстрів співробітників і довідників між застосунками.
  • Дашборди перестають жити в трьох місцях — один центр аналітики.
  • Для користувача — один блок «ефективність» замість блукання між системами.

6. Поетапний план міграції

Головний принцип — нічого не ламати: додаємо нове поряд зі старим, переносимо поступово, вимикаємо старе лише коли нове перевірене.
