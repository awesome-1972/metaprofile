MetaVision — повна карта платформи

Оглядовий документ для технічного партнера / провідного інженера

MetaVision Consulting · підготовлено для передачі · вересень 2026

Що це. MetaVision — набір взаємоповʼязаних веб-застосунків для HR/рекрутингу та оцінки персоналу (SaaS, B2B). Складається з центрального «хабу», трьох основних модулів (ATS, Оцінка PRO, Метапрограми) і кількох сусідніх сервісів. Основний стек: React + TypeScript (Vite, shadcn/Tailwind, MUI) на Cloudflare Pages, бекенд і дані на Supabase (Postgres + Edge Functions на Deno), AI через Anthropic Claude. Історично частину зроблено на платформі Lovable. Один модуль (Метапрограми) ще має окремий NestJS-бекенд на Render, який зараз мігрується в Supabase.

1. Карта платформи (схема)

Суцільні стрілки — прямі залежності; пунктир — опційні/зовнішні виклики. «Аудит процесів» — сусідній модуль, інтеграція планується.

2. Застосунки та їхнє призначення

Studio Hub центральний

Верхній рівень і точка входу. Керує організаціями та доступами, тримає спільні довідники (компетенції, професії), реєстр розробників, і запускає модулі через федеративний SSO. Тут задумано звести реєстр людей і аналітику.

ATS / Metaprofile рекрутинг

Найбільший модуль: вакансії, кандидати, воронка найму, брифи, клієнтський портал, офери, матчинг під бріф, AI-парсинг резюме, інтеграції з job-бордами, звіти по кандидату. ~55 edge-функцій. Має дві генерації UI: V1 (демо) і V2 (прод, реальна автентифікація) — співіснують.

Оцінка PRO (assess-360) оцінка

360°-оцінка, бібліотека компетенцій, реєстр співробітників та ієрархія, профіль співробітника (з PDF), 9-box/DSA/NPS, блок «Організаційний розвиток» з APQC (бібліотека бізнес-процесів, 3 рівні). Мультитенантність через tenants + tenant_admins.

Метапрограми у міграції

Психометричне профілювання: опитування (ситуації/питання), підрахунок метапрограм, шаблони під професії, результати. Історично окремий NestJS-бекенд на Render + власна JWT-автентифікація. Триває перенесення на Supabase (дані вже перенесено; довідники й читання опитування — на edge; записи/підрахунок — у роботі).

Аудит процесів (handoff-process-audit) сусідній

Окремий застосунок для аудиту процесів; планується інтеграція у блок «Організаційний розвиток» (SSO-вхід + seed бібліотеки процесів).

5. Проблеми та технічний борг

Розкидана «ефективність». Performance-функції (360, компетенції, KPI, метапрограми, профіль) розпорошені по 3 застосунках — планова консолідація в єдиний блок Performance Management.
Дублювання даних. Реєстри співробітників і довідники компетенцій частково дублюються між модулями (частину вже зведено в хаб — не завершено).
Метапрограми на платному Render. Окремий NestJS-бекенд ($25/міс) + окрема модель авторизації. Міграція на Supabase edge триває (читання зроблено, записи/підрахунок — попереду).
Дві генерації UI в ATS. V1 (демо) і V2 (прод) співіснують — джерело плутанини; потребує чистого розділення/прибирання демо.
Різнорідна автентифікація. 4 різні схеми ролей у 4 модулях + окремий JWT у Метапрограмах. Потрібна уніфікація (напр., усе на Supabase Auth).
Права БД після міграції. Перенесений дампом проєкт Metaprogram не мав стандартних грантів service_role — виправлено вручну; варто закріпити міграцією.
Мінімум тестів і CI. Автотести/пайплайни майже відсутні (є лише автодеплой edge). Немає системного код-рев'ю та моніторингу помилок.
Велика поверхня edge-функцій. Лише в ATS ~55 функцій із дубльованою логікою (кілька parse-resume, connector-ів) — потребує рефакторингу та спільних утиліт.
Секрети й доступи. Ключі (Anthropic, Resend, job-борди, JWT) розкидані по Supabase/Render/Cloudflare; перед передачею — інвентаризація та ротація.

7. Вимоги до фахівця

Потрібен senior full-stack інженер із досвідом SaaS B2B-продуктів (обовʼязково: мультитенантність, RBAC, SSO, робота з підписками/білінгом на рівні розуміння). Профіль — «продуктовий інженер», що вміє і стабілізувати, і будувати нове, і працювати з AI.

Технічні навички

  • Frontend: React + TypeScript, Vite, Tailwind/shadcn, MUI; SPA-архітектура, стан (TanStack Query).
  • Backend/дані: Supabase (Postgres, RLS, Auth, Storage), SQL/міграції; Edge Functions на Deno; досвід із NestJS (для міграції Метапрограм).
  • DevOps: Cloudflare Pages, GitHub Actions (CI/CD), керування секретами, спостережуваність (логи/моніторинг помилок).
  • AI/LLM: інтеграція Anthropic Claude / інших LLM у продакшн (промпти, структуровані відповіді, вартість/ліміти).
  • Безпека: модель ролей, RLS-політики, захист персональних даних (GDPR), ротація ключів.
  • SaaS B2B: мультитенантність, ізоляція даних клієнтів, SSO/федерація, онбординг організацій.

Задачі, які треба виконати (пріоритезовано)

  • Завершити винесення Метапрограм із Render у Supabase; вимкнути Render; уніфікувати авторизацію.
  • Провести інвентаризацію та ротацію секретів; налаштувати моніторинг помилок і базове CI/тести.
  • Звести дубльовані реєстри/довідники в хаб; прибрати V1-демо з прод-потоку.
  • Побудувати блок Performance Management + Data Integration Hub (конектор Google Sheets → далі CRM/ERP).
  • Рефакторинг edge-функцій ATS (спільні утиліти, дедуплікація конекторів/парсерів).
  • Реалізувати «Живий профіль» і пошук роботодавцем; довести інтеграцію Аудиту процесів.
  • Провести security- та архітектурний рев'ю всієї платформи, скласти план стабілізації.
