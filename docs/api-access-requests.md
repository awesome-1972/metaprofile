# Листи-запити на API-доступ (Work.ua і Robota.ua)

Готові до відправлення зі своїх акаунтів роботодавця. Кожен лист просить **дві можливості**:
1. **Інтеграція** — employer-API для публікації вакансій і автоматичного отримання відгуків (модель, як у PeopleForce).
2. **Сорсинг** — доступ до API бази резюме (пошук кандидатів за фільтрами), як використовують інструменти на кшталт The AIHA.

Перед відправкою підстав контактні дані у блоці «Контакти» (телефон, домен порталу). За потреби додай номер договору роботодавця.

Просимо надати інформацію та доступ до вашого API для двох сценаріїв:

**1. Публікація вакансій і отримання відгуків (employer API):**
- програмна публікація/оновлення/зняття вакансій від імені нашого акаунта роботодавця;
- автоматичне отримання відгуків (кандидатів) на наші вакансії — ПІБ, контакти, текст резюме, супровідний лист, посилання на відгук;
- механізм автентифікації (ключ/токен/OAuth) і ліміти запитів.

**2. Пошук по базі резюме (CV database API):**
- програмний пошук резюме за фільтрами (посада, навички, локація, досвід тощо) у межах нашої платної підписки на доступ до бази;
- отримання структурованих полів профілю та посилання на резюме.

Будь ласка, підкажіть:
- чи доступні ці можливості через ваш API і за яких умов (тариф, партнерська програма, договір);
- технічну документацію (endpoints, автентифікація, ліміти);
- порядок отримання доступу/ключів.

**Кому:** відділ партнерств / технічна підтримка Robota.ua
**Тема:** Запит на API-доступ (публікація вакансій + відгуки + CVDB) для рекрутингового порталу MetaVision

Доброго дня!

Ми — рекрутингова агенція **MetaVision** (акаунт роботодавця на Robota.ua: _[вкажіть email/ID акаунта]_). Розробляємо власний ATS/HR-портал і хочемо офіційно інтегрувати його з Robota.ua. Знаємо, що ви надаєте native-інтеграцію партнерам (нею користуються, зокрема, HR-системи як PeopleForce), тож хотіли б отримати аналогічний доступ для нашої платформи.

Просимо надати інформацію та доступ до вашого API для двох сценаріїв:

**1. Публікація вакансій і отримання відгуків (employer/partner API):**
- програмна публікація/оновлення/зняття вакансій від імені нашого акаунта роботодавця;
- автоматичне отримання відгуків (кандидатів) на наші вакансії — ПІБ, контакти, резюме, супровідний лист, посилання на відгук;
- автентифікація (ключ/токен/OAuth) і ліміти.

**2. Доступ до бази резюме (CVDB API):**
- програмний пошук по базі резюме за фільтрами (40+ параметрів: ключові слова, місто, галузь, досвід, освіта, зарплата тощо) у межах нашої підписки;
- структуровані профілі (кар'єра, навички, мови) + посилання на резюме.

Будь ласка, підкажіть:
- умови надання partner/employer API (тариф, договір, партнерська програма);
- технічну документацію (endpoints, автентифікація, ліміти, вебхуки для відгуків);
- порядок підключення й видачі ключів.
