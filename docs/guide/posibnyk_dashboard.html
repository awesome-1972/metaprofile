Дашборд

Огляд усіх проєктів, команд і людей
Версія 1.0 • Для власника/адміністратора платформи
Дашборд — стартовий екран хаба. Це зведений огляд усіх проєктів, команд і людей, до яких ви маєте доступ: ключові показники, розрахунок бонусів по проєктах і завантаженість команди. Відкривається одразу після входу (пункт «Дашборд» вгорі лівого меню).

1. Ключові показники (KPI)

Верхній ряд — пʼять карток-лічильників зі станом компанії «одним поглядом»:

Scrum-команди
Кількість команд у компанії.
Активні проєкти
Скільки проєктів зараз у роботі.
Учасники команди
Кількість людей, видимих у ваших проєктах.
Загальний бонусний пул
Сумарний бонусний фонд по доступних проєктах (у $).
Середній score
Середня оцінка ефективності по доступних людях.

2. Зведення по доступних проєктах

Таблиця показує економіку кожного проєкту й розрахований бонус. Колонки:

Проєкти
Код проєкту (напр. CI-03, P13).
Складність
Рівень L2–L4 (впливає на коефіцієнт).
Coeff
Коефіцієнт складності (напр. 1.15, 1.30, 1.45).
Actual Revenue
Фактична виручка проєкту.
Ctrl. Margin
Контрольована маржа. Відʼємне значення підсвічується червоним і позначкою ⚠.
Pool Type
Модель бонусного пулу: Fixed Pool (фіксований), Net Profit Pool (від чистого прибутку), Controlled Margin Pool (від маржі).
Bonus Base / Adj. Bonus
Базовий і скоригований (з коефіцієнтом) бонус.
Team Avg Score
Середня оцінка команди проєкту (— якщо ще немає оцінок).
Читання попереджень: червоний ⚠ біля Pool Type / відʼємна маржа означають, що проєкт у мінусі — бонус по ньому нульовий, і його варто переглянути.

3. Bonus Pool та «Видимі люди»

Нижче таблиці — два блоки поруч:

  • Bonus Pool по доступних проєктах — стовпчикова діаграма розміру бонусного пулу по кожному проєкту (швидко видно, де зосереджені гроші).
  • Видимі люди у доступних проєктах — список співробітників із колонками Code, Роль, Зарплата, Бонус, Score.

4. Завантаження команди (Team Load)

Показує, наскільки завантажені люди по проєктах, зі шкалою зон завантаженості (0% → 80% → 90% → 120% → 130% → 150%). Кольори: зелений — оптимально, жовтий — межа, червоний — перевантаження.

Учасник
Імʼя співробітника (клікабельне).
Роль
Роль на проєкті (Middle Developer, Team Lead…).
Проєкт
Код проєкту.
Алокація
Відсоток завантаження на цьому проєкті.
Статус
Підсумкова зона (напр. ⚠ 230% — сильне перевантаження червоним).
«Доступних/видимих» у назвах означає: дашборд показує лише те, що дозволяє ваша роль та організація. Під роллю admin ви бачите всю компанію.
