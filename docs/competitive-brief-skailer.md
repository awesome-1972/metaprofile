# Конкурентний бриф: Skailer (skailer.com)

**Дата:** 2026-08-28 · Джерело: сайт skailer.com + огляди. Контекст: порівняння з платформою MetaVision
(metaprofile ATS + Оцінка PRO + Аудит + метапрограми).

## 1. Що таке Skailer
AI-native **HRM-платформа для середніх компаній**, що обʼєднує три модулі в одному:
- **ATS** (рекрутинг),
- **Core HR** (кадрове ядро),
- **Performance & Goals** (цілі/оцінка ефективності).

Позиціювання: «HR understood. Finally» — платформа-партнер, що не розвалюється зі зростанням
складності оргструктури. EU-хостинг, GDPR, on-prem опція, ручний онбординг і підтримка в
месенджерах (Slack/WhatsApp/Telegram, «15 хв у DM»). Ціна — **від €10/місце/міс**. Цільова
аудиторія — mid-to-large компанії, які прибирають ручні процеси.

## 2. Функціонал (мапа)

**ATS / рекрутинг**
- Кастомні воронки найму з approval-workflow по філіях, SLA на кожен етап, шаблони.
- **Chrome-розширення** для імпорту кандидатів із LinkedIn, Xing, Dribbble, StackExchange, GitHub.
- Внутрішня база резюме/кандидатів з розширеним пошуком.
- Аналітика рекрутингу: time-to-hire, витрати, ефективність джерел, продуктивність рекрутерів, порівняння воронок.

**Core HR** (те, чого MetaVision цілеспрямовано не робить)
- Централізована база співробітників (кастомні поля, дашборди, звіти).
- Оргчарт (департаменти, локації, юрособи, лінії підпорядкування).
- Облік відпусток/присутності з workflow-затвердженням.
- Портал самообслуговування співробітника.

**Інше:** Workflows (автоматизація рутини), Surveys (опитування), API-інтеграції, міграція даних під ключ.

## 3. Skailer vs MetaVision — де хто сильніший

| Вимір | Skailer | MetaVision |

| Первинний користувач | **In-house HR** компанії | **Агенція / executive search** |
| Модель | Керувати своїми співробітниками + наймати | Наймати для КЛІЄНТІВ + глибока оцінка |
| ATS-воронка, аналітика | ✅ Зрілий | ✅ Є (воронка, matching, дашборд) |
| Сорсинг | ✅ **Chrome-ext (LinkedIn/GitHub…)** | ⚠️ Конектори robota/work.ua/Djinni/DOU; LinkedIn — у планах |

## 4. Загроза / можливість для MetaVision
Skailer **не прямий конкурент** у ядрі MetaVision: він продає **широту** (все-в-одному HRM для
внутрішніх команд), а MetaVision виграє **глибиною** (агентська доказова оцінка + доставка клієнту).
Різні покупці: HR-директор середньої компанії vs рекрутингова агенція / замовник executive search.

**Пряме перекриття — лише ATS-механіка** (воронки, база кандидатів, аналітика, сорсинг). Тут Skailer
має дві речі, які MetaVision варто наздогнати: **Chrome-розширення для сорсингу** (LinkedIn/GitHub) і
**зрілу рекрутинг-аналітику** (source effectiveness, recruiter performance).

## 5. Висновки — що взяти, чим диференціюватись
**Взяти в себе (де Skailer сильний):**
- **Chrome-розширення сорсингу** (перегукується з нашим дослідженням Jobin/PeopleGPT) — імпорт
  LinkedIn/GitHub у воронку одним кліком.
- **Глибша рекрутинг-аналітика:** ефективність джерел, продуктивність рекрутерів, порівняння воронок.
- **SLA на етапах воронки** + approval-workflow по «філіях/клієнтах».
- Меседж **EU-хостинг + GDPR + людська підтримка** — у нас це є, але слабко проговорено; варто винести в позиціювання.

**Тримати як моат (де Skailer слабкий):**
- **Доказова оцінка кандидата** (компетенції + AI-звіт з розділенням факт/оцінка/висновок, 360, DSA,
  **метапрограми**, аудит зрілості) — цього в HRM-сюїтах немає.
- **Клієнтський бік** (портал + звіти замовнику) — агентська цінність, якої Skailer не має за визначенням.

**Стратегічний висновок:** не намагатися стати «ще одним all-in-one HRM» (там Skailer та десятки інших).
Поглиблювати **агентську оцінку + доставку клієнту** як диференціатор, а з ATS-механіки вибірково
наздогнати сорсинг-розширення й аналітику. Продавати не «широту», а **об'єктивність найму на основі
доказів** — те, чого суїти на кшталт Skailer структурно не дають.
